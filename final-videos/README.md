# Финально принятые ролики

Сюда команда `pnpm reel accept <build>` копирует только final/public-рендеры с пройденным QA.

Структура создаётся автоматически по формату:

```text
final-videos/
  survive-500/
    survive500-try1.mp4
    survive500-try1.json
```

JSON рядом с видео — квитанция принятия: номер попытки, версия математической модели, build ID, QA-статус и SHA-256. Уже принятое имя нельзя затереть другим роликом.

MP4 и квитанции являются локальными производственными артефактами и не добавляются в git.
